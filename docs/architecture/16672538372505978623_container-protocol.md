# Container Protocol

The contract between the host (claude-container), the image, and the entrypoint.

## Image Requirements

The base image (`ghcr.io/hypermemetic/claude-container:latest`) provides everything. Custom Dockerfiles MUST extend it:

```dockerfile
FROM ghcr.io/hypermemetic/claude-container:latest
# Add your tools here
RUN apt-get update && apt-get install -y ...
```

### Critical Binaries (no fallback)

| Binary | Purpose | Validated |
|--------|---------|-----------|
| `gosu` | Privilege drop from root to developer | Pre-creation + resume |
| `git` | All workspace operations | Pre-creation + resume |
| `claude` | Claude Code CLI | Pre-creation + resume |
| `bash` | Entrypoint, agent-run | Assumed (base image) |

### Soft Binaries (warning only)

| Binary | Purpose | Fallback |
|--------|---------|----------|
| `python3` | Trust dialog setup | Hardcoded JSON |
| `sudo` | Rootish mode (developer + sudo) | Use `--as-root` instead |
| `docker` | Docker-in-Docker | Only if `--docker` flag |
| `locales` | Locale support | Warns, unsets LC_ALL |

### Custom Dockerfiles Must NOT

- Set `USER` — the entrypoint starts as root and drops to developer via gosu
- Override `ENTRYPOINT` or `CMD` — claude-container mounts its own entrypoint
- Delete `/home/developer` — the entrypoint creates the developer user there

## Container Lifecycle

```
host: claude-container -s myproj
  │
  ├─ validate image (gosu, git, claude)
  ├─ detect stale container (6 checks)
  │   └─ rebuild if any check fails
  ├─ docker run --user 0:0 ... (always root entry)
  │
  └─ INSIDE CONTAINER:
      ├─ entrypoint.sh (as root)
      │   ├─ token setup
      │   ├─ locale check
      │   ├─ user creation (groupadd, useradd)
      │   ├─ config setup AS developer (su developer)
      │   │   ├─ mkdir .claude, .cargo, .npm, .cache/pip
      │   │   ├─ trust dialog (.claude.json)
      │   │   ├─ statusline settings (.claude/settings.json)
      │   │   └─ copy .gitconfig
      │   ├─ sudo setup (if rootish)
      │   ├─ install fin command
      │   ├─ CLAUDE.md injection (task-specific)
      │   ├─ resolve working directory (.main-project)
      │   └─ exec gosu developer agent-run [args]
      │
      └─ agent-run.sh (as developer)
          ├─ snapshot repo HEADs
          ├─ claude "$@"
          ├─ diff repo HEADs (post-agent)
          └─ write .agent-result
```

## Container Rebuild Triggers

On every launch, the host checks these 6 conditions for stopped containers. If ANY fails, the container is removed and recreated (volume preserved):

| # | Check | What it catches |
|---|-------|-----------------|
| 1 | Image ID changed | Image rebuilt with same name |
| 2 | Image name changed | Different image entirely |
| 3 | Entrypoint mount path | Switched between installed and dev |
| 4 | Container user ≠ root | Created before --user 0:0 fix |
| 5 | Stale env vars | CONTINUE_SESSION=1 baked in |
| 6 | Critical tools missing | Bad image that got through |

Plus corrupted mount detection (token dir instead of file).

## Volumes

| Volume | Mount | Purpose | Persists |
|--------|-------|---------|----------|
| `claude-session-{name}` | `/workspace` | Git repos, config, markers | Yes |
| `claude-state-{name}` | `/home/developer/.claude` | Conversation history | Yes |
| `claude-cargo-{name}` | `/home/developer/.cargo` | Cargo cache | Yes |
| `claude-npm-{name}` | `/home/developer/.npm` | npm cache | Yes |
| `claude-pip-{name}` | `/home/developer/.cache/pip` | pip cache | Yes |

## Environment Variables (host → container)

| Var | Required | Purpose |
|-----|----------|---------|
| `CLAUDE_CODE_OAUTH_TOKEN` | Yes | API auth (from secret mount or env) |
| `HOST_UID` / `HOST_GID` | Yes | File ownership |
| `PLATFORM` | Yes | Host OS detection |
| `RUN_AS_ROOTISH` | Default true | Developer + sudo |
| `AGENT_TASK` | Default "work" | Task type for CLAUDE.md injection |
| `CLAUDE_SESSION_NAME` | If session | Statusline display |

## Marker Files (in /workspace)

| File | Written by | Read by | Purpose |
|------|-----------|---------|---------|
| `.claude-projects.yml` | Session creation | Everything | Multi-project config |
| `.main-project` | Host (cwd resolution) | Entrypoint | Startup directory |
| `.repo-manifest` | Session creation | Extraction | Rename detection |
| `.agent-result` | agent-run.sh | Host exit handler | Post-agent report |
| `.merge-into-branch` | session_merge_into | Host exit handler | Merge target |
| `.merge-into-summary` | session_merge_into | Entrypoint | Claude's conflict prompt |
| `.merge-into-mounts` | session_merge_into | Host (docker args) | Host repo mounts |
| `.sync-branch` | session_sync | Host exit handler | Sync target |
| `.sync-summary` | session_sync | Entrypoint | Claude's rebase prompt |
| `.reconcile-complete` | fin command | Host exit handler | Resolution description |
| `.merge-verify` | reconcile --verify | Host exit handler | Gate 2 flag |
