# Code Audit Findings

Date: 2026-03-21

## Critical Bugs

### 1. Wrong argument to `resolve_repo_host_path` (reconcile.sh:203)

`resolve_repo_host_path` is called with `$volume` (a Docker volume name like `claude-session-foo`) instead of `$projects` (a `name|path` string). The function silently falls through to its CWD fallback, returning an incorrect host path. Any downstream sync/merge logic that depends on this path operates against the wrong directory.

### 2. Argument order mismatch in `check_repo_sync_status` (reconcile.sh:207)

The function signature is `(session_head, host_path, session_name, target_branch)` but the call site passes `(proj_name, proj_head, host_path, session_name)`. This means:

- `proj_name` (a repo name string) is interpreted as `session_head` (a git SHA)
- `target_branch` is never provided (missing 4th argument)

The sync status check is fundamentally broken — it compares a repo name against git state and omits the branch entirely.

### 3. Stale state reads via `get_session_heads` (reconcile.sh:194)

Reconcile uses `get_session_heads` instead of `snapshot_session_state`. This violates the unified snapshot architecture established in commit `5dbb901` ("one docker run for all state reading"). Each call to `get_session_heads` spawns a separate `docker run`, which:

- Creates unnecessary container overhead
- Reads state that may be inconsistent with other snapshot data already collected
- Defeats the atomicity guarantee the snapshot system was designed to provide

## Dead Code

Nine functions are defined but never called anywhere in the codebase:

| Function | Location | Purpose |
|----------|----------|---------|
| `spin` | lib/utils.sh | Spinner animation |
| `find_worktree_for_branch` | lib/utils.sh | Git worktree lookup |
| `create_git_session` | lib/session-mgmt.sh | Session creation |
| `get_host_gid` | lib/platform.sh | Host group ID lookup |
| `get_ssh_socket_args` | lib/docker-utils.sh | SSH socket argument builder |
| `has_multi_project_config` | lib/config.sh | Multi-project config check |
| `map_volumes_to_sessions` | lib/session-mgmt.sh | Volume-to-session mapping |
| `setup_dev_caches` | lib/docker.sh | Dev cache setup |
| `setup_session_state` | lib/docker.sh | Session state initialization |

These are candidates for removal. They add cognitive load during code review and risk being mistakenly called with stale signatures.

## Test Suite Staleness

3 of 4 test scripts fail due to CLI flags that were removed during refactoring:

| Test Script | Broken Flags | Failure Rate |
|-------------|-------------|--------------|
| test-workflows.sh | `--extract`, `--sync`, `--merge-into` | 13/20 tests fail |
| test-merge-subcommand.sh | `merge` subcommand | 10/13 tests fail |
| test-multi-project.sh | `--extract` | All fail |

Only `test-agent-layer.sh` passes (tests `entrypoint`/`agent-run` directly, no removed flags).

The test suite provides false confidence — a green CI would require ignoring 3 of 4 test files, and running all 4 produces a misleading failure rate that obscures real regressions.

## Backward Compatibility Aliases

The snapshot writes `pre_session_head` and `pre_target_head` as aliases of `session_head` and `target_head`. These are only read by `pull/report.sh`. They are not harmful but represent redundant state. Once `report.sh` is updated to read the canonical keys directly, these aliases can be removed to simplify the snapshot format.

## What's Clean

- No `TODO`, `FIXME`, or `HACK` comments in the codebase
- No unsafe unquoted variables in critical paths
- Consistent use of `local` with declaration split from assignment (avoids masking `$?`)
- Proper `trap`-based cleanup throughout
- `_pull_result_set`/`_pull_result_get` pattern for structured data passing between functions
- All paths configurable via environment variables (no hardcoded paths)

## Recommended Priority

1. **Fix the three critical bugs** — reconcile is non-functional for multi-project setups
2. **Fix or delete the test suite** — broken tests are worse than no tests
3. **Remove dead code** — 9 functions, pure noise
4. **Remove backward compat aliases** — minor cleanup after report.sh update
